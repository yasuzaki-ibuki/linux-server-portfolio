# Step 4:勤怠・日報アプリ(PostgreSQL、バックアップと復元)

出勤・退勤の打刻、日報の登録、月ごとの集計ができるWebアプリ。
データベースにPostgreSQLを使い、自動バックアップと復元テストまで行った。

## 構成

```
ブラウザ → Nginx(/kintai/)→ gunicorn(127.0.0.1:8003)→ Flask(app.py)→ PostgreSQL 18(ソケット接続)

systemdタイマー(毎日3:00)→ backup.sh → pg_dump → /var/backup/kintai(7日分保持)
```

## 機能

- 打刻:出勤・退勤ボタン(二重打刻はSQLの条件で防止)、今月の勤怠一覧
- 日報:やったこと・課題・明日やることを日付ごとに登録・編集
- 月次集計:月の全日付について勤務時間と日報の有無を表示、出勤日数・合計・平均を集計

## ファイル

| ファイル | 役割 |
|---|---|
| app.py | 画面の表示と、打刻・日報・集計の処理 |
| db.py | PostgreSQLへの接続(peer認証、ソケット経由) |
| schema.sql | テーブル定義(勤怠・日報) |
| templates/ | 画面(共通部分・打刻・日報一覧・日報入力・月次集計) |
| backup.sh | バックアップの取得・検証・古いファイルの削除 |
| kintai.service | アプリのsystemdサービス設定 |
| kintai-backup.service / .timer | バックアップを毎日3時に実行するsystemd設定 |
| requirements.txt | 必要なPythonパッケージの一覧 |

## データベースの設計

- PostgreSQL 18をRocky Linuxの標準リポジトリ(モジュール)から導入
- 待ち受けは 127.0.0.1 のみ(外部から接続不可)であることを ss コマンドで確認
- アプリ用のDBユーザーは一般権限(Superuserではない)とし、必要最小限の権限で運用
- peer認証(Linuxのユーザー名で本人確認)を使い、パスワードを設定ファイルに書かない構成
- 勤務日・日報日にUNIQUE制約、退勤が出勤より前にならないようCHECK制約を設定
- 日報は INSERT ... ON CONFLICT DO UPDATE(UPSERT)で新規・更新を1回で処理
- 月次集計は generate_series で月の全日付を作り、勤怠・日報を LEFT JOIN で結合

## バックアップと復元

- pg_dump(カスタム形式)で毎日3時に自動取得(systemdタイマー)
- Persistent=true を設定し、3時に停止していた場合も次回起動時に実行
- 取得直後に pg_restore -l で読み取れることを確認(壊れたバックアップを防ぐ)
- 7日を過ぎたバックアップは自動削除し、ディスクの逼迫を防止
- バックアップは中身に個人の勤怠情報を含むため、保存場所の権限を700に設定
- 復元テスト:日報を全件削除 → アプリを停止 → pg_restore --clean で復元 → 件数と画面で復旧を確認

## 運用・監視

- systemdでサービス化(After=/Wants= でPostgreSQLの起動後に起動)
- 監視(Step 2)の対象に kintai と postgresql の両方を追加
- 停止試験
  - kintaiを停止:502 Bad Gateway(Nginxがアプリに到達できない)、LINEで異常・復旧を通知
  - PostgreSQLを停止:kintaiのサービスは active のままだが 500 Internal Server Error。アプリのログ(journalctl -u kintai)で接続エラーを確認。依存するデータベースも監視する必要性を確認

## 構築中に発生したトラブル

- 事象:復元コマンドを実行すると、何も表示されずに止まった
- 原因:`-d`(戻し先のDB名)の後ろにDB名を書き忘れ、バックアップファイル名がDB名として解釈された。ファイルの指定がなくなったため、pg_restoreが標準入力からの入力を待っていた
- 対処:Ctrl+Cで中断し、`-d kintai` を指定して再実行
- 学び:コマンドが無反応で止まったときは、入力待ちの可能性を疑う

## 今後の課題

- バックアップが同じサーバー内にあるため、サーバー自体の故障には対応できない。別の場所(クラウドのストレージなど)への保存を検討
- バックアップの失敗を監視・通知する仕組みの追加
