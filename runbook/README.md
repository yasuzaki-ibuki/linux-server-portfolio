# Runbook(運用手順書)

このサーバー環境で、障害や定常作業が発生したときに、誰が対応しても同じ手順で確認・対処できるようにまとめた手順書です。
構築中に実際に発生した障害と、その対応の経験をもとに作成しています。

## 対象環境

| サーバー | アドレス | 役割 |
|---|---|---|
| rocky9-web | 192.168.56.10 | Nginx・Webアプリ(家計簿・監視・作業記録・勤怠)・PostgreSQL |
| rocky9-node | 192.168.56.11 | Ansibleで構築される側(予定) |

## 手順書の一覧

| # | 手順書 | 状態 |
|---|---|---|
| 1 | Web画面が開かない(502/500エラー) | 
| 2 | サービスが起動しない | 作成済み |
| 3 | 監視から異常通知が来たとき(初動) | 作成予定 |
| 4 | バックアップからの復元 | 作成予定 |
| 5 | サーバーの再起動作業 | 作成予定 |
| 6 | ファイアウォールの設定変更 | 作成予定 |
| 7 | 新しいサービスを追加するときのチェックリスト | 作成予定 |

## 共通のルール

- 作業前に現在の状態を確認・記録し、作業後に同じコマンドで確認する
- 設定を変更するときは、変更前に切り戻し手順を用意する
- 対応が終わったら、作業記録アプリ(/worklog/)に事象・原因・対処・再発防止を登録する
